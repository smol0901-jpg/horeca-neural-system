# Horeca Neural System

**Продвинутая система управления безопасностью пищевых продуктов и операциями для ресторанов, кафе и столовых (ХоРеКа).**

Соответствие **СанПиН 2.3/2.4.4282-26** (с 01.09.2026), принципам **ХАССП**, ТР ТС 021/2011.

## Живое демо

**https://smol0901-jpg.github.io/horeca-neural-system/**

Что видно прямо сейчас:
- Live-симуляция датчиков (температура, влажность, двери) с порогами
- Электронные журналы (температуры, бракераж, гигиена)
- Критические контрольные точки (ККТ) плана ХАССП
- Склад FIFO + контроль сроков годности
- Дашборд соответствия требованиям Роспотребнадзора
- Нейросетевой ассистент (экспертная система v0.1)
- Переключатель режима БД: **SQLite (локально)** / **PostgreSQL (облако)**
